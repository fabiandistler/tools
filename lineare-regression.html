Lineare Regression

Von der Idee über die Kleinste-Quadrate-Schätzung bis zu Inferenz, Annahmen und den typischen Fehlinterpretationen — mit Reglern zum Selbstausprobieren.

Was die Regression eigentlich tut

Eine lineare Regression beantwortet eine sehr konkrete Frage: Wie verändert sich der Erwartungswert einer Zielgröße y, wenn sich eine erklärende Größe x um eine Einheit ändert?

Sie ersetzt damit die einfachste denkbare Vorhersage — „nimm immer den Mittelwert von y" — durch eine bessere: „nimm den Mittelwert von y für diesen Wert von x". Genau das ist die Bedeutung der Regressionsgeraden: sie ist eine Schätzung der bedingten Erwartung E[y | x].

„Linear" bezieht sich auf die Koeffizienten, nicht auf die Form der Kurve. y = β₀ + β₁·x + β₂·x² ist ein lineares Modell, weil β₀, β₁, β₂ linear eingehen — es zeichnet trotzdem eine Parabel. Nicht linear wäre dagegen etwas wie y = β₀ · x^β₁.

Diese Trennung ist der Kern der gesamten Inferenz: β̂₁ ist eine Zufallsvariable, weil sie von der zufällig gezogenen Stichprobe abhängt. Ein anderer Datensatz aus derselben Grundgesamtheit hätte einen anderen Wert ergeben. Wie stark er schwankt, sagt der Standardfehler — siehe Tab Inferenz.

Wann ist Regression das richtige Werkzeug?

  • Beschreiben: Wie hängen Merkmale zusammen, wenn man andere konstant hält? — funktioniert fast immer.
  • Vorhersagen: Welchen Wert erwarte ich für eine neue Beobachtung? — funktioniert, solange sie im beobachteten Wertebereich liegt.
  • Kausal erklären: Was passiert, wenn ich x aktiv verändere? — funktioniert nur unter zusätzlichen, inhaltlichen Annahmen. Der Tab Fallstricke zeigt, warum.

Die beste Gerade — von Hand gesucht

Die Kleinste-Quadrate-Methode (Ordinary Least Squares, OLS) wählt die Gerade, für die die Summe der quadrierten senkrechten Abstände zu den Punkten minimal wird. Schieben Sie die Regler und versuchen Sie, die Fehlerquadratsumme SSE zu unterbieten — das gelingt nicht, das Minimum ist eindeutig.

Ihre Gerade OLS-Optimum Residuen

Warum Quadrate — und nicht Beträge?

  • Es gibt eine geschlossene Lösung. Ableiten der Quadratsumme nach β₀ und β₁, gleich null setzen, fertig — kein Suchverfahren nötig.
  • Sie schätzt den bedingten Mittelwert. Absolutbeträge (LAD-Regression) würden den bedingten Median schätzen — robuster, aber eine andere Frage.
  • Unter den Gauß-Markov-Annahmen ist OLS BLUE: unter allen linearen erwartungstreuen Schätzern hat er die kleinste Varianz.
Der Preis: Quadrieren gewichtet große Abweichungen stark. Ein einzelner Ausreißer kann die Gerade sichtbar verbiegen — ziehen Sie oben einen Punkt weit nach oben und beobachten Sie das OLS-Optimum.

Die Lösung in geschlossener Form

β̂₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)² = Cov(x, y) / Var(x)
β̂₀ = ȳ − β̂₁ · x̄

Zwei Eigenschaften folgen direkt daraus und gelten immer, egal wie gut das Modell passt:

  • Die Gerade geht exakt durch den Schwerpunkt (x̄, ȳ).
  • Die Residuen summieren sich zu null und sind unkorreliert mit x. Ein Muster im Residuenplot ist deshalb immer ein nichtlineares Muster.

Bei mehreren Prädiktoren schreibt man dasselbe in Matrixform: β̂ = (XᵀX)⁻¹Xᵀy. Ist eine Spalte von X eine exakte Linearkombination anderer Spalten, ist XᵀX nicht invertierbar — das ist perfekte Multikollinearität, etwa bei der Dummy-Falle.

Wie viel Streuung erklärt das Modell?

Nullmodell: nur der Mittelwert ȳ

Abweichungen zum Mittelwert → SST

Regressionsmodell: die OLS-Gerade

Abweichungen zur Geraden → SSE

SST = SSR + SSE     R² = SSR / SST = 1 − SSE / SST

R² richtig einordnen

  • R² ist der Anteil der Streuung von y, den das Modell erklärt. R² = 0,64 heißt: 64 % der Varianz sind gebunden, 36 % bleiben unerklärt.
  • R² steigt mechanisch mit jeder zusätzlichen Variable — auch mit reinem Zufallsrauschen. Deshalb gibt es das korrigierte R̄², das für die Zahl der Parameter bestraft: R̄² = 1 − (1−R²)·(n−1)/(n−k). Nur R̄² kann sinken, wenn eine Variable nichts beiträgt.
  • Ein hohes R² beweist kein gutes Modell. Das Anscombe-Quartett im Tab Fallstricke zeigt vier völlig verschiedene Datensätze mit identischem R² = 0,67.
  • Ein niedriges R² beweist kein schlechtes Modell. In Querschnittsdaten über Menschen sind R² von 0,2–0,4 normal. Ein Koeffizient kann präzise geschätzt und inhaltlich wichtig sein, während der größte Teil der individuellen Streuung unerklärt bleibt.
  • Für Vorhersagegüte ist der RMSE informativer, weil er in der Einheit von y steht: „im Mittel liege ich um X daneben".
R² ist nur zwischen Modellen mit derselben abhängigen Variable vergleichbar. Ein Modell für y und eines für log(y) haben nicht vergleichbare R².

Der Zusammenhang zur Korrelation

In der einfachen Regression mit einem Prädiktor gilt R² = r², wobei r der Pearson-Korrelationskoeffizient ist. Und die Steigung lässt sich schreiben als β̂₁ = r · (s_y / s_x).

Daraus folgt die Namensgebung: Ein Punkt, der bei x eine Standardabweichung über dem Mittel liegt, liegt bei y erwartungsgemäß nur r Standardabweichungen über dem Mittel — er fällt zum Mittelwert zurück. Genau diese Regression zur Mitte beobachtete Francis Galton 1886 an Körpergrößen von Eltern und Kindern und gab dem Verfahren damit seinen Namen.

Der Koeffizient ist eine Zufallsvariable

Hier wird eine bekannte Wahrheit simuliert: y = 5 + β₁·x + ε. Sie sehen also, was Sie in echten Daten nie sehen — den wahren Wert. Ziehen Sie mehrfach neue Stichproben und beobachten Sie, wie stark β̂₁ um den wahren Wert schwankt.

Beobachten Sie: n vervierfachen halbiert die Streuung (SE ∝ 1/√n). σ verdoppeln verdoppelt sie. Ein größerer Wertebereich von x hilft ebenfalls — deshalb steht Var(x) im Nenner der SE-Formel.

Drei verbreitete Fehldeutungen. (1) Der p-Wert ist nicht die Wahrscheinlichkeit, dass die Nullhypothese stimmt. (2) „Nicht signifikant" heißt nicht „kein Effekt", sondern „mit diesen Daten nicht von null unterscheidbar" — bei kleinem n oft trotz großem Effekt. (3) Statistische Signifikanz ist keine inhaltliche Relevanz: bei n = 100.000 wird auch ein Effekt von 0,3 % signifikant. Immer die Effektgröße samt Konfidenzintervall berichten, nicht nur Sternchen.

Konfidenzband ≠ Prognoseband

  • Das Konfidenzband beschreibt die Unsicherheit über den bedingten Mittelwert E[y|x]. Es wird mit wachsendem n beliebig schmal.
  • Das Prognoseband beschreibt die Unsicherheit über eine einzelne neue Beobachtung. Es enthält zusätzlich die Fehlerstreuung σ und bleibt deshalb auch bei n → ∞ breit.

Für die Frage „wie hoch ist das mittlere Gehalt bei 10 Jahren Erfahrung?" gilt das Konfidenzband. Für „was verdient diese eine Person?" das Prognoseband. Beide sind an den Rändern des x-Bereichs breiter — die Gerade ist dort am schlechtesten bestimmt.

Mehrere Prädiktoren: „unter sonst gleichen Bedingungen"

In der multiplen Regression y = β₀ + β₁x₁ + β₂x₂ + … + ε ändert sich die Interpretation von β₁ grundlegend: es ist der Effekt von x₁ bei konstant gehaltenen übrigen Variablen. Technisch gesehen misst β₁ den Zusammenhang zwischen dem Teil von x₁ und dem Teil von y, die jeweils nicht durch die anderen Variablen erklärt werden (Frisch-Waugh-Lovell-Theorem).

Genau daraus entstehen die beiden wichtigsten Probleme der Praxis — und beide lassen sich hier durchspielen.

Omitted Variable Bias

Fehlt eine relevante Variable, wird ihr Effekt der korrelierten enthaltenen Variable zugeschlagen. Die Verzerrung ist exakt bezifferbar:

E[β̂₁kurz] = β₁ + β₂ · δ    mit    δ = Cov(x₁,x₂)/Var(x₁)

Man braucht also beides, damit ein Bias entsteht: Die weggelassene Variable muss y beeinflussen (β₂ ≠ 0) und mit x₁ korrelieren (δ ≠ 0). Stellen Sie oben ρ = 0 ein — die Verzerrung verschwindet, obwohl x₂ weiter fehlt.

Das Vorzeichen ist vorhersagbar: Sind β₂ und ρ beide positiv, wird β̂₁ überschätzt. Haben sie unterschiedliche Vorzeichen, wird unterschätzt — bis hin zum Vorzeichenwechsel. Genau das steckt hinter Aussagen wie „nach Kontrolle für Position und Erfahrung schrumpft der Gehaltsunterschied von 18 % auf 5 %".

Omitted Variable Bias ist das zentrale Argument gegen kausale Interpretation von Beobachtungsdaten. Er lässt sich nicht durch mehr Daten heilen — nur durch bessere Variablen oder ein besseres Design.

Multikollinearität

Sind Prädiktoren stark korreliert, lässt sich ihr Beitrag kaum noch trennen. Die Schätzer bleiben erwartungstreu, aber ihre Standardfehler explodieren: Koeffizienten werden groß, instabil und wechseln bei kleinen Datenänderungen das Vorzeichen.

VIFj = 1 / (1 − R²j)     SE(β̂j) wächst mit √VIFj

R²j ist dabei das Bestimmtheitsmaß aus der Regression von xj auf alle anderen Prädiktoren. Faustregeln: VIF > 5 kritisch prüfen, VIF > 10 handeln.

Was tun? Variablen zusammenfassen oder eine weglassen; einen Index bilden; regularisieren (Ridge); oder — häufig die beste Antwort — nichts tun, wenn nur Vorhersage das Ziel ist. Multikollinearität schadet der Vorhersage kaum, sondern nur der Interpretation einzelner Koeffizienten.

Perfekte Multikollinearität ist ein anderer Fall: dort ist XᵀX nicht invertierbar und das Modell gar nicht schätzbar. Klassiker ist die Dummy-Falle — nimmt man für eine Variable mit k Kategorien alle k Dummys plus Achsenabschnitt auf, summieren sich die Dummys zur Eins-Spalte. Eine Kategorie muss als Referenz entfallen.

Kategorien, Interaktionen, Nichtlinearität

  • Dummy-Variablen: Eine Kategorie ist Referenz, jeder Koeffizient misst die Differenz zu ihr. Der Achsenabschnitt gehört zur Referenzgruppe.
  • Interaktionen (x₁ · x₂): erlauben, dass der Effekt von x₁ vom Wert von x₂ abhängt. Achtung: Bei aufgenommener Interaktion ist β₁ nur noch der Effekt von x₁ an der Stelle x₂ = 0 — Variablen vorher zentrieren macht das interpretierbar.
  • Quadratische Terme (x + x²): erlauben Krümmung. Der Effekt ist dann β₁ + 2β₂x und damit selbst vom Niveau abhängig. Nie x² ohne x aufnehmen.
  • log-Transformationen: log(y) → Koeffizienten als Prozenteffekte lesbar (exakt: e^β − 1); log(x) und log(y) gemeinsam → Elastizität.

Einflussreiche Beobachtungen

Drei verschiedene Dinge werden oft in einen Topf geworfen:

  • Ausreißer — ungewöhnlicher y-Wert bei normalem x. Erhöht vor allem die Fehlerstreuung.
  • Hebelpunkt (Leverage) — extremer x-Wert. Gefährlich, weil er die Gerade drehen kann. Kennzahl: hii, auffällig ab 2k/n.
  • Einflussreiche Beobachtung — beides zusammen: Sie verändert das Ergebnis tatsächlich. Kennzahlen: Cook's D (Gesamteinfluss) und DFBETAS (Einfluss auf einen einzelnen Koeffizienten, auffällig ab 2/√n).

Nur die dritte Gruppe ist ein Problem. Und die richtige Reaktion ist fast nie „löschen", sondern: nachsehen, ob ein Datenfehler vorliegt, sonst Ergebnis mit und ohne die Beobachtung berichten.

Diagnose-Checkliste

  1. Residuen vs. angepasste Werte — der wichtigste Plot. Erwartet: strukturloses Band um null. Trichter → Heteroskedastizität, Bogen → Nichtlinearität.
  2. Q-Q-Plot der Residuen — Abweichungen an den Enden zeigen schwere Ränder.
  3. Scale-Location-Plot (√|standardisierte Residuen| vs. Fit) — Heteroskedastizität deutlicher als im Rohplot.
  4. Residuen vs. Zeit/Index — bei zeitlicher Ordnung Pflicht (Durbin-Watson ≈ 2 bedeutet keine Autokorrelation).
  5. Einflussdiagnostik — Cook's D, Leverage, DFBETAS.
  6. VIF für alle Prädiktoren.
Im Zweifel robust rechnen. Heteroskedastie-robuste Standardfehler (HC3) kosten bei korrekt spezifiziertem Modell fast nichts und retten bei Verletzung viel. Bei gruppierten Daten geclusterte Standardfehler auf der Ebene, auf der die Zuordnung stattfindet.

Anscombe-Quartett: gleiche Statistik, andere Welt

Vier Datensätze, die in fast jeder Kennzahl übereinstimmen: gleicher Mittelwert von x und y, gleiche Varianzen, gleiche Regressionsgerade ŷ = 3,00 + 0,500·x, gleiches R² = 0,67, gleicher t-Wert. Nur das Bild verrät den Unterschied.

Die Lehre ist nicht „Kennzahlen sind nutzlos", sondern: immer zuerst plotten. Fall II braucht einen quadratischen Term, Fall III eine robuste Methode oder die Prüfung des Ausreißers, Fall IV ist überhaupt nicht schätzbar — die Steigung hängt an einer einzigen Beobachtung.

Simpson-Paradox

Derselbe Datensatz, zweimal ausgewertet: einmal ohne, einmal mit Berücksichtigung der Gruppe. Das Vorzeichen des Effekts dreht sich.

Ein realistisches Beispiel: Innerhalb jeder Abteilung steigt das Gehalt mit den Jahren im Unternehmen — im Gesamtvergleich sinkt es scheinbar, weil die gut bezahlten Abteilungen im Schnitt jüngere Belegschaften haben. Beide Zahlen sind rechnerisch korrekt; nur eine beantwortet die gestellte Frage.

Welche Auswertung richtig ist, entscheidet nicht die Statistik, sondern das inhaltliche Modell: Ist die Gruppe eine Störgröße (beeinflusst x und y), muss man für sie kontrollieren. Ist sie ein Mediator (liegt kausal zwischen x und y), zerstört Kontrollieren genau den Effekt, den man messen wollte.

Korrelation, Kausalität und der Griff zur Kontrollvariable

Ein signifikanter Koeffizient bedeutet: In diesen Daten gehen x und y systematisch zusammen. Er bedeutet nicht, dass eine Änderung von x eine Änderung von y bewirkt. Drei Alternativen sind immer im Spiel:

  • Umgekehrte Kausalität — y beeinflusst x. (Mehr Beratungsstunden bei kritischen Projekten: Beratung sieht so aus, als verschlechtere sie das Ergebnis.)
  • Gemeinsame Ursache — eine dritte Variable treibt beide. Das ist der Omitted Variable Bias aus dem vorigen Tab.
  • Selektion — die Stichprobe ist nicht zufällig entstanden. Wer nur Bewerber betrachtet, die eingestellt wurden, misst systematisch verzerrt.
Mehr Kontrollvariablen sind nicht automatisch besser. Kontrolliert man einen Collider — eine Variable, die von x und y beeinflusst wird —, entsteht eine Scheinkorrelation, wo vorher keine war. Welche Variablen ins Modell gehören, folgt aus dem angenommenen Kausalmodell, nicht aus dem Modellfit.

Weitere klassische Fehler

  • Extrapolation — Vorhersagen außerhalb des beobachteten x-Bereichs. Das Modell hat dort keine Information; die Gerade läuft trotzdem weiter.
  • Achsenabschnitt überinterpretieren — β₀ ist der Erwartungswert bei x = 0. Liegt x = 0 außerhalb der Daten (z. B. „Körpergröße 0"), ist er reine Rechengröße. Zentrieren macht ihn interpretierbar.
  • Stufenweise Variablenauswahl (Stepwise) — verzerrt Koeffizienten und p-Werte systematisch, weil dieselben Daten für Auswahl und Test benutzt werden.
  • p-Hacking — genügend Spezifikationen durchprobieren, bis eine signifikant ist. Bei 20 Tests ist im Schnitt einer zufällig signifikant.
  • In-Sample-Güte als Vorhersagegüte verkaufen — R² auf den Trainingsdaten ist optimistisch. Für Vorhersage zählt Kreuzvalidierung.
  • Ökologischer Fehlschluss — Zusammenhänge auf Aggregatebene (Abteilungen, Länder) auf Individuen übertragen.
  • Kennzahl-Fetisch — Sternchen berichten statt Effektgröße und Konfidenzintervall.

Arbeitsablauf für eine belastbare Analyse

  1. Frage präzisieren: beschreiben, vorhersagen oder kausal erklären? Davon hängt alles Weitere ab.
  2. Daten ansehen — Verteilungen, fehlende Werte, Ausreißer, Streudiagramme. Vor jedem Modell.
  3. Modell aus der Sache heraus spezifizieren, nicht aus dem Fit heraus: Welche Variablen gehören inhaltlich hinein, welche sind Collider?
  4. Schätzen und Koeffizienten in Fachsprache übersetzen („pro zusätzlichem Jahr … bei gleicher Position").
  5. Diagnostik — Residuenplots, Einflussdiagnostik, VIF.
  6. Robustheit prüfen: alternative Spezifikationen, mit/ohne einflussreiche Fälle, robuste Standardfehler.
  7. Berichten mit Effektgröße, Konfidenzintervall, n und den Annahmen — nicht mit Sternchen allein.

Umsetzung in R und Python

# --- R ---
m <- lm(gehalt ~ erfahrung + ausbildung + geschlecht, data = df)
summary(m)                       # Koeffizienten, SE, t, p, R2, F
confint(m)                       # Konfidenzintervalle
par(mfrow = c(2, 2)); plot(m)    # die vier Standard-Diagnoseplots
car::vif(m)                      # Multikollinearitaet
lmtest::coeftest(m, vcov = sandwich::vcovHC(m, type = "HC3"))   # robuste SE
predict(m, newdata = neu, interval = "prediction")              # Prognoseband
# --- Python (statsmodels) ---
import statsmodels.formula.api as smf
m = smf.ols("gehalt ~ erfahrung + ausbildung + C(geschlecht)", data=df).fit()
print(m.summary())
m_rob = m.get_robustcov_results(cov_type="HC3")   # robuste SE
m.conf_int()

from statsmodels.stats.outliers_influence import variance_inflation_factor, OLSInfluence
OLSInfluence(m).cooks_distance[0]                 # Cook's D
